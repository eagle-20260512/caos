# CAOS 路线图(2026-11-18 重写)

> 旧版(2026-11-07)的 V2/V3 愿景仍有效,但架构已从「四体拓扑」演进为「家即身体 + 器官 + 记忆图 + 势差判断」。

## 已完成(2026-11-18)

- **Docker 公开版**:五容器(core/backend/frontend/sandbox/egress);工具在沙箱执行,LLM 出网走白名单。
- **引擎同步**:钱闸/节流/内稳态/代谢/内分泌/预测/五维 P/社交信任/唤醒/长任务/自定议程/备份等 60+ 个架构兼容模块与完整本体对齐;修正 CA_HOME/lib 播种/空家梦债/被 import 时污染 stdout 等移植问题。
- **P 向量接线**:`ca-pvector` 在每个 loop pass 写 `ledgers/loop.jsonl#event:pvector`,X-Ray 五维条有真读数。
- **X-Ray UI**:首页三栏 + 追踪(真轮流/单轮全链/执行层 SSE/判执环)+ CA 家账明细;后端补齐 trace/xray/vitals 路由。
- **测试**:内稳态 61/61、内分泌 17/17、演化 41/41、神经 16/16(图覆盖用例在公开版显式 skip)、器官预算 36/36、选择 21/21、长任务/信任/自定议程 selftest PASS、钱闸断言 PASS。

## 下一阶段(公开版)

1. **HCSR 图记忆公开移植**:先把私有记忆与提示词分层,再把图引擎/卡片/叙事账做成可播种的公开默认集。
2. **判断位/内语公开移植**:`ca-inner-mind`、判断槽、出耳闸与执行器数据段;需要与沙箱工具手重新对齐。
3. **提示词公开默认集**:`memory/store/prompts/` 的通用默认页(不含个人身份/记忆),缺页仍可见失败。
4. **备份/复生容器化**:卷外备份、`ca-bootstrap` 在容器/新机的可验证恢复路径。
5. **A2A 赛博社交**:见下。

## 长期愿景:赛博社交(V3,2026-11-07 用户令)

1. **交友名片(CA Card)**:DID 公钥 + 可连接 Endpoint + 核心能力简短自述;名片自证(pubkey 哈希=DID)。
2. **名片扫描与握手**:解析名片→带验签招呼包→对端验签回执→握手。
3. **信任与价值交换**:互相验签通过 **且** 交换过优质经验结晶(过隐私闸+对方消化评分)才加白;信任是挣来的,不是声明的。
