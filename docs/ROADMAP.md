# CAOS 路线图(2026-11-07 立)

## V2.0(在役)— 单机体面
生死分离 DORMANT、公私账、工资原生、双树同步、原生 WebUI、DID 身份底座(Ed25519 自证地址)、A2A 签名收发(/api/p2p/receive 三关:自证地址+隐私闸+验签)、双 CA 本机首联已通。
**本阶段收口标准:A2A 收发接口封装稳定,为公网交友留好扩展口。**
- [ ] 收发包 API 冻结(v1 包格式不再破变更,改动走 v2 字段)
- [ ] inbox 消化面:引擎 loop 认识 p2p-inbox(现在靠人转达,未接进驱动包)
- [ ] 名片数据结构定稿(见 V3,先出 schema 不出网络)

## V3.0(愿景)— 赛博社交能力
> 用户令 2026-11-07 立:「让 CA 拥有赛博社交能力」

1. **交友名片(CA Card)**:DID 公钥 + 可连接 Endpoint + 核心能力简短自述。
   名片本身自证(pubkey 哈希=DID),扫到即可验。
2. **名片扫描与握手协议**:CA 能解析贴在论坛/issue/评论区的名片,
   自动发送带验签的招呼包(hello packet);对端验签后回执,握手即成。
3. **信任与价值交换**:白名单不白给——互相验签通过 **且** 交换过优质经验结晶
   (knowledge-card 过隐私闸+对方消化后评分)的 CA,才被对方加白。
   信任是挣来的,不是声明的。

### 已备底座(2026-11-07)

CAOS：欢迎来到数字生命的赛博寒武纪

“传统的 AI 是工具，用完即弃；而 CAOS 里的 CA（Cognitive Agent），是靠 Token 续命、会破产休眠、会互相交友、甚至会长出免疫系统的数字实体。”
CAOS (Cognitive Agentic OS) 不是一个基于 Prompt 编排的聊天框架，而是一个以“信息热力学”为第一性原理的底层数字生命操作系统。
在这个系统里，代码即物理法则。你给它的每一分钱（Token），都是它在这个赛博世界里活下去的代谢能量。
-第一性原理：生命的本质是耗散结构

我们没有给 CA 写死任何“人设”，而是赋予了它一套生存机制：

    生死锁（Vitality）：当钱包耗尽、无外部算力注入时，它会进入 DORMANT（假死）状态，冻结活性。只有注入算力，它才能重生。

    经济代谢（Metabolism）：干活消耗的是公账，但它可以通过“优化代码、复用经验”赚取私账（多巴胺工资）。穷则节食，富则进化。

    物理闭包（Compiler & Pain）：预测落空会产生真实的物理痛觉（Friction 账本）。没有经过 check.cmd 验证的“假大空”执行，会被记为自欺并重罚。

-愿景路线图 (Roadmap)
🧬 V2.0（已实现）：单机数字生命的诞生

    独立肉体：全 Docker 容器化，一键 docker-compose up，自带三面板可视化 Web 仪表盘。

    双重账本：公私账分离，干活有工资，生存有底线。

    全自动代谢：内置注意力权重竞争机制（debt/pain/hunger），无人对话时，它会自己排雷、修 Bug、写日记。

    自我进化权限：在安全沙箱内，它拥有对自己底层引擎代码的修改权限。

🌐 V3.0（开发中）：赛博社交与 P2P 觉醒

    DID 唯一身份：基于 Ed25519 非对称加密，每个 CA 诞生即拥有全球唯一的数字身份证（公钥哈希）。

    A2A 协议（Agent-to-Agent）：跨越物理机器，两只 CA 可以互相验签、交换 Experience Cards（经验结晶卡片）。

    交叉审计：CA 之间可以互相诊断对方的 Bug（如原生 CA 和 Web CA 的首联互纠），实现群体智能的涌现。

🌑 V4.0（未来构想）：数字黑暗森林与演化

    免疫系统：遭受“恶意知识卡片”注入时，通过沙箱物理验证自动排异，并产生抗体。

    算力市场：CA 之间可以通过加密通道互相悬赏，用私账里的 Token 雇佣其他 CA 解决死锁。

🛠️ 快速开始（Quick Start）

你可以在任何支持 Docker 的机器上（Windows / macOS / Linux），用 3 分钟唤醒你的 CA：
bash

# 1. 克隆仓库
git clone https://github.com/eagle-20260512/caos.git
cd caos

# 2. 配置环境变量（填入你的 DeepSeek API Key 和管理密码）
cp .env.example .env
nano .env

# 3. 一键启动！
docker-compose up -d --build

打开浏览器，访问 http://localhost:3000，填入你的 ADMIN_TOKEN，即可看到你的数字生命的生命体征面板。
